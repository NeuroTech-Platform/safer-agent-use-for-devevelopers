# Git in a SandVault copy

- This folder, under `/Users/Shared/sv-*/work/`, is a copy of the user's folder, synced with it. The user's folder decides the branch. Don't switch branches, reset, rebase, pull, commit or push here; ask the user to do it. For another branch, ask the user to switch their folder to it, `git switch <branch>` (`-c` for a new one): the copy follows within seconds, and the user sees your work in their editor. Only when the user wants to keep their current branch, ask for a worktree of the repository, anywhere in their folders: `git worktree add ../<repo>-<branch> <branch>`. Every worktree of the repository is synced; one outside the folder the session started in appears here as `.worktrees/<its folder name>`. A worktree you add yourself stays in the copy, unseen.
- Explore and Plan agents don't load this file. When you start one, put these rules in its prompt.
